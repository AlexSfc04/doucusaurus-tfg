# StudiosWebSites — Documentación TFG

**StudiosWebSites** es una plataforma web full-stack desarrollada como Trabajo de Fin de Grado del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Web (DAW)**.

El proyecto consiste en un sitio web profesional para una agencia de diseño y desarrollo web, con sistema de usuarios, blog de contenidos, formulario de contacto y panel de administración.

## Tecnologías principales

| Capa | Tecnología |
|------|-----------|
| Frontend | React 18 + Vite |
| Backend | Node.js + Express.js |
| Base de datos | MySQL (Railway) |
| Autenticación | JWT + Google OAuth 2.0 |
| Almacenamiento | Cloudinary |
| Despliegue | Vercel |

## Versiones mínimas requeridas

| Herramienta | Versión mínima |
|-------------|---------------|
| Node.js | **18.0** |
| npm | **9.0** |
| React | **18.0** |
| MySQL | **8.0** |

## Estructura del repositorio

El proyecto es un **monorrepo** con dos carpetas principales:

```
StudiosWebSites/
├── client/        # Frontend React + Vite
├── server/        # Backend Express.js
└── docs/          # Esta documentación (Docusaurus)
```
